GO-LANG

Go is a simple, fast and concurrent programming language.
In short Go = C + strings + garbage collector + concurrency

Features:
    1. Compile Time: 
        Google has historically struggled with long compile times for its projects having large codebases.
        Go is designed for faster compilation without the need for dependency checking.

    2. String processing: 
        Google frequently processes and analyzes large amounts of text data in the form of web pages, requiring efficient manipulation of strings.
        Go programming language has a comprehensive set of string functions. which also uses garbage collection to make working with strings more efficient compared to some other languages like C++.
    
    3. Garbage collection: 
        Go includes a garbage collector that automatically manages memory, making it easier for developers to write code without having to worry about memory management.

    4. Concurrency: 
        Concurrency in Go refers to the ability of a program to execute multiple tasks independently but not necessarily simultaneously. It's about structuring your program in a way that allows different parts of it to run independently, making efficient use of available resources.

        While concurrency is about managing many tasks, parallelism is about executing tasks simultaneously.
        For example, if there are four tasks and two executors And the two executors are performing their task. Suppose task executor 1 has completed its task so it will not be waiting for the executer 2 to complete its task. And it will be picking up the next available task.

        In Go, a goroutine is a lightweight thread managed by the Go runtime.

    2. Package names are tightly coupled with folders.

Variables:
    VARIABLES IN GO

    1. Variables store data.
        Example: var name string = "Nakul"
        Go can automatically detect type.
        Example: var city = "Chandigarh"

    2. Short Variable Declaration
        Used inside functions only.
        Example:
        name := "Nakul"
        age := 22

    3. Multiple Variable Declaration
        var a, b int = 10, 20
        OR
        x, y := 5, 10

    4. Default Values
        If value not assigned, Go gives default value.

        int     -> 0
        string  -> ""
        bool    -> false

        Example:
        var num int
        fmt.Println(num)

        Output:
        0

    5. Constants
    Value cannot change.
    const pi = 3.14


    6. Variable Naming Rules
        - Cannot start with number
        - No spaces
        - Case-sensitive

        Valid:
        userName
        age
        totalAmount

        Invalid:
        1name
        user name

    7. Exported Variables
        Capital letter -> public/exported  => you can use this variable in some other file as well
            > var Name string = "public"
        Small letter -> private
            > var name string = "private"

        same thing is applicable for finctions as well
        this is the reason Println function is having capital letter so that it can be used across many files and folders


INPUT AND OUTPUT:

    OUTPUT IN GO

        1. fmt.Print()

        Prints output on same line.

        Example:

        fmt.Print("Hello")
        fmt.Print("World")

        Output:
        HelloWorld


        2. fmt.Println()

        Prints output with new line.

        Example:

        fmt.Println("Hello")
        fmt.Println("World")

        Output:
        Hello
        World


        3. fmt.Printf()

        Used for formatted output.

        Example:

        name := "Nakul"
        age := 22

        fmt.Printf("My name is %s and age is %d", name, age)

        Output:
        My name is Nakul and age is 22


        COMMON FORMAT SPECIFIERS

        %s -> string
        %d -> integer
        %f -> float
        %t -> boolean

    ----------------------------------------

    INPUT FROM USER

        Used with fmt.Scan()

        Example:

        var name string

        fmt.Print("Enter name: ")
        fmt.Scan(&name)

        fmt.Println("Hello", name)


        IMPORTANT

        &name means:
        "store input at memory address of name variable"


        MULTIPLE INPUTS

        Example:

        var a int
        var b int

        fmt.Scan(&a, &b)

        fmt.Println(a + b)


        Example Input:
        10 20

        Output:
        30


        TAKING FULL LINE INPUT

        fmt.Scan() stops at space.

        For full line input use:

        bufio + os

        Example:

        reader := bufio.NewReader(os.Stdin)

        text, _ := reader.ReadString('\n')


    ----------------------------------------

    SHORT SUMMARY

    fmt.Print()    -> same line output
    fmt.Println() -> output with new line
    fmt.Printf()  -> formatted output
    fmt.Scan()    -> user input
    &variable     -> memory address


ERROR HANDLING:
    1. Go does not use try-catch.
    2. Functions usually return:
        value, err
        Example:
        result, err := someFunction()
    3. Check errors:
        if err != nil {
            fmt.Println(err)
        }
    4. nil = no error
    5. Ignore value using underscore (_)
        Example:
        _, err := someFunction()
    6. Ignore error: result, _ := someFunction()
    7. Create custom error: err := errors.New("invalid input")
    8. panic() -> crashes program
    9. recover() -> handles panic
 
    Note: We use _ For the scenarios where we want to Ignore one of the outputs of the function.


ARRAY VS SLICE:

    ARRAY

    1. Fixed size

    var arr [3]int = [3]int{1,2,3}

    OR

    arr := [3]int{1,2,3}

    2. Size is part of type

    [3]int and [4]int are different types

    3. Printing array

    fmt.Println(arr)

    Output:
    [1 2 3]


    ----------------------------------

    SLICE

    1. Dynamic size

    slice := []int{1,2,3}

    2. No fixed size

    []int

    3. Printing slice

    fmt.Println(slice)

    Output:
    [1 2 3]


    ----------------------------------

    MAIN DIFFERENCE

    Array  -> fixed size
    Slice  -> dynamic size

    [3]int -> array
    []int  -> slice


    SHORT SUMMARY

    Array:
    arr := [3]int{1,2,3}

    Slice:
    slice := []int{1,2,3}


FOR LOOP:
    1. Go has only one loop:
    for

    ----------------------------------

    2. Basic loop

    for i := 0; i < 5; i++ {
        fmt.Println(i)
    }

    ----------------------------------

    3. While loop style

    i := 0

    for i < 5 {
        fmt.Println(i)
        i++
    }

    ----------------------------------

    4. Infinite loop

    for {
        fmt.Println("Running")
    }

    ----------------------------------

    5. range loop

    nums := []int{10,20,30}

    for index, value := range nums {
        fmt.Println(index, value)
    }

    ----------------------------------

    6. Ignore value/index using _

    for _, value := range nums {
        fmt.Println(value)
    }

    SHORT SUMMARY

    for -> loop
    range -> iterate array/slice/map/string
    _ -> ignore value

FILE HANDLING:
    Import:

    import (
        "fmt"
        "os"
    )

    ----------------------------------

    FLOW OF FILE HANDLING

    Create/Open File
            ↓
    Read / Write Data
            ↓
    Close File

    ----------------------------------

    1. CREATE FILE

    file, err := os.Create("test.txt")

    if err != nil {
        fmt.Println(err)
        return
    }

    defer file.Close()

    ----------------------------------

    2. WRITE TO FILE

    file.WriteString("Hello Nakul")

    ----------------------------------

    3. READ FILE

    data, err := os.ReadFile("test.txt")

    if err != nil {
        fmt.Println(err)
        return
    }

    fmt.Println(string(data))

    ----------------------------------

    4. APPEND DATA

    file, _ := os.OpenFile(
        "test.txt",
        os.O_APPEND|os.O_WRONLY,
        0644,
    )

    defer file.Close()

    file.WriteString("\nNew Data")

    ----------------------------------

    5. DELETE FILE

    os.Remove("test.txt")

    ----------------------------------

    6. RENAME FILE

    os.Rename("old.txt", "new.txt")

    ----------------------------------

    7. CHECK FILE EXISTS

    _, err := os.Stat("test.txt")

    if err == nil {
        fmt.Println("File exists")
    }

    ----------------------------------

    IMPORTANT

    defer file.Close()

    Means:
    Close file automatically at end.

    ----------------------------------

    SHORT SUMMARY

    os.Create()   -> create file
    os.ReadFile() -> read file
    WriteString() -> write data
    os.OpenFile() -> append/open
    os.Remove()   -> delete file
    os.Rename()   -> rename file
    os.Stat()     -> check exists

    u.RawQuery = params.Encode()

    ----------------------------------

    5. Final URL

    fmt.Println(u.String())

    ----------------------------------

    6. Create URL

    u := url.URL{
        Scheme: "https",
        Host:   "google.com",
        Path:   "/search",
    }

    fmt.Println(u.String())

    ----------------------------------

    SHORT SUMMARY

    url.Parse() -> parse URL
    u.Query()   -> get query params
    params.Add() -> add query param
    u.String()  -> final URL


JSON ENCODING & DECODING:
    Import:

    import "encoding/json"

    ----------------------------------

    STRUCT EXAMPLE

    type User struct {
        Name string
        Age  int
    }

    ----------------------------------

    1. JSON ENCODING
    (Go -> JSON)

    user := User{
        Name: "Nakul",
        Age:  22,
    }

    data, err := json.Marshal(user)

    fmt.Println(string(data))

    Output:
    {"Name":"Nakul","Age":22}

    ----------------------------------

    2. JSON DECODING
    (JSON -> Go)

    jsonData := `{"Name":"Nakul","Age":22}`

    var user User

    json.Unmarshal([]byte(jsonData), &user)

    fmt.Println(user.Name)

    Output:
    Nakul

    ----------------------------------

    3. JSON TAGS

    type User struct {
        Name string `json:"name"`
        Age  int    `json:"age"`
    }

    Output:
    {"name":"Nakul","age":22}

    ----------------------------------

    IMPORTANT

    Marshal()   -> encode to JSON
    Unmarshal() -> decode JSON

    ----------------------------------

    SHORT SUMMARY

    Go Struct -> Marshal() -> JSON
    JSON -> Unmarshal() -> Struct

        func handlePostRequest(myurl string) {
            // post funtion third argument me data lega jo ki Reader format me hoga isliye hume struct ko Reader format me convert karna padega
            // Struct -> JSON -> String -> Reader
            newUser1 := UserData{
                UserId: 101,
                Title: "New Todo",
                Completed: false,
            }

            jsonData, err := json.Marshal(newUser1) // this will convert the struct data into json format and store it in jsonData variable
            if err != nil {
                panic(err)
            }

            // option 1: json to string to reader
            jsonToString:= string(jsonData) // this will convert the json data into string format
            jsonToReader := strings.NewReader(jsonToString) // this will convert the json data into reader format which is required by the post function

            // option 2: json to reader
            // jsonToReader := bytes.NewBuffer(jsonData) // this will convert the json data into reader format which is required by the post function

            postRes, postError := http.Post(myurl, "application/json", jsonToReader) // this will send a post request to the server with the data in json format

            // post kia hua data dekhne ke liye
            if postError != nil {
                panic(postError)
            }
            defer postRes.Body.Close()
            postData, _ := io.ReadAll(postRes.Body) // this will read the data from the response body in format array of bytes
            fmt.Println("postData: ", string(postData))

        }

        func handlePutRequest(myurl string) {
            // put funtion third argument me data lega jo ki Reader format me hoga isliye hume struct ko Reader format me convert karna padega
            // Struct -> JSON -> String -> Reader

            putUrl := myurl + "/1" // this will update the data of the user with id 1 from the server
            updatedUser1 := UserData{
                UserId: 101,
                Title: "Updated Todo",
                Completed: false,
            }

            jsonData, err := json.Marshal(updatedUser1) // this will convert the struct data into json format and store it in jsonData variable
            if err != nil {
                panic(err)
            }

            // option 1: json to string to reader
            jsonToString:= string(jsonData) // this will convert the json data into string format
            jsonToReader := strings.NewReader(jsonToString) // this will convert the json data into reader format which is required by the put function

            // option 2: json to reader
            // jsonToReader := bytes.NewBuffer(jsonData) // this will convert the json data into reader format which is required by the put function

            putReq, _ := http.NewRequest("PUT", putUrl, jsonToReader) // direct PUT method nahi hai isliye hume NewRequest function ka use karna padega aur usme method, url aur data dena padega
            // isse sirf abhi request create hui hai
            putReq.Header.Set("Content-Type", "application/json") // isse hum content type set kar rahe hai ki hum json format me data bhej rahe hai or ye important hai kyuki server ko pata chalega ki hum kis format me data bhej rahe hai

            client := &http.Client{} // isse hum ek client create kar rahe hai jo ki request ko server tak bhejega
            res, err := client.Do(putReq) // isse hum request ko server tak bhej rahe hai aur res me server se aane wala response store ho jayega aur err me agar koi error aata hai to wo store ho jayega
            if err != nil {
                panic(err)
            }

            defer res.Body.Close()
            putData, _ := io.ReadAll(res.Body) // this will read the data from the response body in format array of bytes
            fmt.Println("putData: ", string(putData))

        }

            res, err := client.Do(putReq) // isse hum request ko server tak bhej rahe hai aur res me server se aane wala response store ho jayega aur err me agar koi error aata hai to wo store ho jayega
            if err != nil {
                panic(err)
            }

            defer res.Body.Close()
            putData, _ := io.ReadAll(res.Body) // this will read the data from the response body in format array of bytes
            fmt.Println("putData: ", string(putData))

        }

            deleteUrl := myurl + "/201" // this will delete the data of the user with id 1 from the server

GOROUTINES:
    lightweight thread managed by Go runtime
    GOROUTINES is used to concurrently process two tasks at a time. 
    We do not need to wait for one task to complete to Start another task 
    Normal:
        Cook food
        THEN
        Wash clothes
        THEN
        Watch TV

    GO:
        Food cooking
        while
        you wash clothes

    Code:
        package main

        import (
            "fmt"
            "time"
        )

        func task(name string) {

            for i := 1; i <= 5; i++ {

                fmt.Println(name, i)

                time.Sleep(500 * time.Millisecond)
            }
        }

        func main() {

            go task("Task A")

            go task("Task B")

            time.Sleep(4 * time.Second)
        }
        Output:
        Task A 1
        Task B 1
        Task B 2
        Task A 2
        Task A 3
        Task B 3
        Task B 4
        Task A 4
        Task A 5
        Task B 5
        Goroutines do NOT guarantee order.


WAITGROUP:
    WaitGroup (sync package)

    // Used to wait for goroutines to finish.
    // Without WaitGroup:
    // main() may finish early
    // → all goroutines stop

    // --------------------------------------------

    // Import

    import "sync"

    // --------------------------------------------

    // Create WaitGroup

    var wg sync.WaitGroup

    // --------------------------------------------

    // Important Functions

    // 1. Add(n)
    // Tells Go how many goroutines to wait for

    wg.Add(3)

    // --------------------------------------------

    // 2. Done()
    // Marks one goroutine as completed

    defer wg.Done()

    // --------------------------------------------

    // 3. Wait()
    // Blocks execution until all goroutines finish

    wg.Wait()

    // --------------------------------------------

    // Flow

    /*
    Add()
    ↓
    Start Goroutines
    ↓
    Done()
    ↓
    Wait()
    ↓
    Program Ends
    */

    // --------------------------------------------

    // Example

    package main

    import (
        "fmt"
        "sync"
    )

    func task(name string, wg *sync.WaitGroup) {

        defer wg.Done()

        fmt.Println(name)
    }

    func main() {

        var wg sync.WaitGroup

        wg.Add(2)

        go task("A", &wg)
        go task("B", &wg)

        wg.Wait()

        fmt.Println("All Tasks Completed")
    }

    // --------------------------------------------

    // Important Notes

    // WaitGroup only synchronizes goroutines.
    // It does NOT:
    // - create threads
    // - control scheduler
    // - guarantee execution order

    // Best Practice:
    // Use defer wg.Done() inside goroutine.
    CODE:
        package main

        import (
            "fmt"
            "sync"
        )

        func task(name string, wg *sync.WaitGroup) {
            defer wg.Done() // Signal completion when the function returns

            fmt.Println(name)
        }

        func main() {
            fmt.Println("Started")

            var wg sync.WaitGroup
            wg.Add(2) // matlab 2 goroutine ka wait karna hai

            go task("Task A", &wg) // Start a goroutine for Task A
            go task("Task B", &wg) // Start a goroutine for Task B

            wg.Wait() // Wait for all goroutines to finish

            fmt.Println("Finished")
        }
